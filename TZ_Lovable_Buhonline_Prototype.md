# ТЗ для Lovable: Прототип платформы мэтчинга для Бухонлайн

## Цель
Создать **кликабельный прототип** (не полную реализацию) для тестирования новой системы мэтчинга предпринимателей и бухгалтеров на портале Бухонлайн.

---

## Что нужно создать

### 3 экрана для тестирования:

1. **Главная страница портала** (с нативными элементами)
2. **Страница статьи** (с нативными блоками)
3. **Hub — страница мэтчинга** (основной продукт)

---

## ЭКРАН 1: Главная страница (Homepage)

### Дизайн
**Референс:** Точно как на скриншоте главной Бухонлайн
- Header: синий (#0066CC или #0052A3)
- Акцентные блоки: синий (#0066CC)
- Фон: белый (#FFFFFF)
- Карточки: белый с лёгкой тенью
- Шрифт: системный (Arial, Roboto)

### Структура страницы

## Технические требования

### Stack
- **Framework:** React + TypeScript (или что умеет Lovable)
- **Styling:** Tailwind CSS или styled-components
- **State management:** React hooks (useState)
- **Routing:** React Router (если нужно)

### Responsive
- Desktop: 1200px+ (основной)
- Tablet: 768-1199px (опционально)
- Mobile: 320-767px (обязательно для FAB и форм)

### Интерактивность

**Что должно работать:**
1. ✅ Все кнопки кликабельны и ведут куда надо
2. ✅ Форма multi-step с переключением шагов
3. ✅ Progress bar обновляется
4. ✅ FAB открывает/закрывает modal
5. ✅ Калькулятор в статье считает и меняет текст
6. ✅ Sticky bar закрепляется при скролле
7. ✅ Карточки бухгалтеров интерактивны (hover эффекты)

**Что НЕ нужно:**
- ❌ Реальная отправка данных (просто console.log)
- ❌ Backend и API
