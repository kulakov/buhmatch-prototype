Как тестировать на реальном сайте

Откройте buhonline.ru и вставьте в консоль браузера (F12 → Console):

var s = document.createElement('script');
s.src = 'https://kulakov.github.io/buhmatch-prototype/widget.js';
document.body.appendChild(s);

Код для GTM

Custom HTML тег:

<script src="https://kulakov.github.io/buhmatch-prototype/widget.js"></script>

События dataLayer

Откройте консоль (F12) — там логируются все события:

📊 buhmatch_init
📊 buhmatch_answer { field: 'industry', value: 'Торговля' }
📊 buhmatch_like { accountant: 'Анна Сидорова' }
📊 buhmatch_match { accountant: '...', data: {...} }
