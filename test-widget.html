Виджет БухМэтч

Справа внизу должна появиться фиолетовая кнопка с иконкой чата.

Нажмите на неё, чтобы открыть виджет.

Код для GTM

Custom HTML тег:

<script src="https://kulakov.github.io/buhmatch-prototype/widget.js"></script>

События dataLayer

Откройте консоль браузера (F12) и смотрите события:

// Виджет пушит такие события:
dataLayer.push({ event: 'buhmatch_init' })
dataLayer.push({ event: 'buhmatch_answer', buhmatch_field: 'industry', buhmatch_value: 'Торговля' })
dataLayer.push({ event: 'buhmatch_like', buhmatch_accountant: 'Анна Сидорова' })
dataLayer.push({ event: 'buhmatch_match', buhmatch_accountant: '...', buhmatch_data: {...} })
