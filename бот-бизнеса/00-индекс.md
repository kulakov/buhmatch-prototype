# Бот бизнеса — карта экранов

Кликабельный прототип бота для предпринимателя.

[[../00-Навигация|← Назад к навигации]]

---

## Как пользоваться

1. Откройте [[00-старт|Старт]]
2. Кликайте по ссылкам как по кнопкам
3. Каждый файл = один экран бота

---

## Структура

```
00-старт
    ↓
01-регистрация → инн → ок
    ↓
02-меню ← главный хаб
    ├── Найти бухгалтера → ../анкета/00-старт
    ├── 03-запросы → ответы на запросы
    ├── 04-отправка → отправка документов
    └── 05-статус → статус задач

Дополнительно:
├── 06-уведомление — входящее от бухгалтера
├── 07-напоминание — напоминание о сроках
└── 08-обратная-связь — оценка работы
```
