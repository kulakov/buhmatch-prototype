# Анкета поиска бухгалтера

Пошаговый прототип анкеты. Каждый файл — один экран.

[[../00-Навигация|← Назад к навигации]]

---

## Как пользоваться

1. Откройте [[00-старт|Старт]]
2. Кликайте по ссылкам как по кнопкам
3. Каждая страница — один экран бота

---

## Структура анкеты

```
00-старт
    ↓
01-отрасль → ответы (7 вариантов)
    ↓
02-форма → ответы (4 варианта)
    ↓
03-налоги → ответы (6 вариантов)
    ↓
03а-смена-режима → ответы (4 варианта)
    ↓
04-задачи → ответы (2 пути)
    ↓
05-документы → ответы (5 вариантов)
    ↓
06-оборот → ответы (7 вариантов)
    ↓
07-сотрудники → ответы (5 вариантов)
    ↓
08-результат → список бухгалтеров
    ↓
09-карточка → заявка
    ↓
10-заявка (финиш)
```

---

## UX-паттерны

| Паттерн | Где применяем |
|---------|---------------|
| **Progress bar** | Каждый экран: `████░░░░` + «Шаг N из 7» |
| **Микро-награды** | После каждого ответа — ценность |
| **Кнопки** | Варианты ответов — ссылки |
| **Опция пропуска** | Оборот: «Не хочу отвечать» |
| **Loss aversion** | Шаг 6: «почти готово!», Шаг 7: «финиш!» |
